# Solmara — Open-World Crime Sandbox
A self-contained 3D city sandbox. Run `node serve.ts` and open http://localhost:8080/game/. All visuals are generated locally; the game has no runtime network dependencies.

WASD move or drive, mouse drag orbit, Shift run, Space handbrake, E steal/exit, F punch, Q pistol, LMB shoot, R reset, Esc pause, M mute. Start a mission from the title screen or roam freely.
